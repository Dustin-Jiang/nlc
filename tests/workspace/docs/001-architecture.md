# 架构总览

基于 Rust + ratatui 构建的 TUI 矩阵计算器，支持矩阵编辑、基础运算与高级线性代数操作。

核心约束：

- 单二进制可执行文件
- 矩阵最大维度 10×10
- 元素类型 `f64`，结果四舍五入到 4 位小数
- 全键盘驱动

## 整体架构

三层架构，App 状态机居中协调：

```
┌─────────────┐    ┌──────────────┐    ┌────────────────┐
│  Input      │───>│  App State   │───>│  UI Render     │
└─────────────┘    └──────┬───────┘    └────────────────┘
                          │
                    ┌─────▼──────┐
                    │  Matrix    │
                    │  Engine    │
                    └────────────┘
```

## 模块职责

| 模块 | 职责 |
|------|------|
| 入口 | 初始化终端、事件循环、分发 tick |
| 应用状态 | 管理 Mode / Matrix / 历史 / 错误 |
| 矩阵引擎 | 矩阵数据结构 + 数学运算 |
| TUI 渲染 | 布局、组件绘制、调色板 |
| 输入处理 | 键盘事件解析、命令映射 |
